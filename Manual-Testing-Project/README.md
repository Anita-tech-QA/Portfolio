# Koel App — Artists Feature (Manual UI Testing)

This project validates the Artists feature of the Koel music streaming application through manual UI and exploratory testing. All testing was performed against the Koel QA environment and managed in Jira (Zephyr) as part of a structured QA workflow.

The goal was to ensure users can browse, search, and play music from multiple artists, with UI data accurately reflecting database records.

## What this project demonstrates
- Manual UI and functional testing  
- Exploratory testing techniques  
- Test case design aligned with Jira/Zephyr  
- Evidence-based defect reporting  
- Validation of UI behaviour against database records  
- Organised QA documentation suitable for a professional portfolio  

## Coverage includes
- Artists visible in the UI  
- Searching for existing artists  
- Case‑insensitive and invalid/empty search behaviour  
- Playing songs from selected artists  
- Verifying artist information  
- Matching UI data with database records  
- Audio streaming validation  

## Repository structure
- **Test-Cases** — structured manual test cases with evidence  
- **Bug-Reports** — defects with clear reproduction steps and screenshots  
- **Evidence** — screenshots used across test cases and bug reports  

## Documented defects include
- Incorrect search results  
- Artists grouped under “Unknown Artist”  
- UI not matching database records  
- Invalid search returning incorrect
